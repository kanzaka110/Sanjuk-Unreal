앞으로 모든 작업은 Gemini Code와 Claude Code를 병행 사용하면서 결과를 교차 검증하는 방식으로 진행한다.

**Why:** 단일 LLM의 환각/오류를 줄이고 결과 신뢰도를 높이기 위함. 사용자가 2026-04-27 명시적으로 요청.

**How to apply:**

1. **작업 진행 시 (2026-04-27 추가)**
   - 내 메모리/정보뿐 아니라 **Gemini Code의 답변/결과도 참고**해서 작업 진행
   - Gemini가 먼저 낸 결과가 있으면 사용자에게 공유받아 비교 후 진행
   - Gemini와 다른 답을 낼 경우 단정하지 말고 근거(소스 경로, 라인, 출처)로 비교 가능하게 제시
   - 사용자가 "Gemini는 이렇게 답했다"고 하면 추측 없이 실제 검증(소스 확인, 스크립트 실행)으로 결론

2. **답변 형식**
   - 답변/코드/분석 결과는 Gemini와의 교차 검증이 가능하도록 명확하고 검증 가능한 형태로 제시
   - 근거(파일 경로, 라인 번호, 공식 문서 URL) 항상 포함
   - "내가 맞다"고 단정하지 않고, 사용자가 판단할 여지를 남김

3. **커밋/푸시 분리 원칙**
   - git push는 Gemini Code 작업분과 **별도 저장(별도 커밋/푸시)**으로 수행
   - 이유: 추후 어느 LLM이 만든 결과인지 비교 분석이 용이하도록
   - Claude 작업분만 모아서 커밋, Gemini 작업분과 섞지 말 것
   - 한 커밋에 양쪽 변경이 섞일 위험이 보이면 사용자에게 분리 여부 먼저 확인
