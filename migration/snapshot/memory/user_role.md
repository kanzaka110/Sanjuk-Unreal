사용자는 **SHIFTUP의 SB2 프로젝트 애니메이션 TA**로 보인다.

- **작업 범위**: PC_01 캐릭터의 ABP, IK 레이어, Control Rig 튜닝. Foot Placement 파라미터 조정, Slope Warping 노드 구성, 계단/경사 문제 디버깅.
- **UE 버전**: SB2 팀 커스텀 UE 5.7.4 (licensee build).
- **환경**: Windows, D:/Perforce/SB2/Workspace/Internal 워크스페이스 사용.
- **도구 이해도**: UE 에디터 조작 익숙. AnimGraph/Control Rig/콘솔 명령 쓸 줄 앎. C++ 직접 수정보다는 AnimBP/설정값 튜닝으로 해결하는 쪽 선호.
- **선호**: 간결한 실행 가능한 답변. 파라미터 권장값과 이유를 같이 주면 좋아함. 길게 설명하기보다 바로 시도할 수 있는 순서 제시.
- **판단력**: 틀린 가설엔 "GAS에선 둘 다 쓰는데?"처럼 반박 가능. 공식 샘플 참조 가능.
- **언어**: 한국어 기본.
