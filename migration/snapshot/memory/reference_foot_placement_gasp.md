## 핵심 설계

- **Toe(발끝)를 IK 목표**로 삼음 (Ankle 아님). 최종 IK 해법 시 발끝에서 발목 역산.
- Rig에 `animated_ctrl`로 발끝+pelvis 저장.

## 4단계 파이프라인

### 1단계: 루트 본 이동 적응 ★ 계단 덜컥 해결 키
- 캡슐 StepUp/Down 시 루트 본의 **지면 노멀 Z 성분은 제거 → 매 프레임 캡슐 위치로 보간**.
- 지면 수평 성분은 보존.
- 경사면에선 Z 성분 변화 없어 보간 불필요 → 완전 밀착.
- **SB2 FootClamp엔 이 로직 없음**: 단순 회전 리미터뿐. 계단 덜컥거림의 직접 원인 후보.

### 2단계: 환경 쿼리
- 무릎 높이에서 발끝 위로 전방 체크 → 캡슐 밖으로 나간 발이 벽 관통 방지.
- 발끝 위↓ → 발끝 아래 트레이스로 floor 위치/노멀 산출.

### 3단계: 발 잠금 (Skew Warp 방식)
- `contact_l/r` 애니 커브로 잠금 타이밍 제어.
- 4상태: 미잠금→잠금시작 / 잠금유지 / 잠금해제희망 / 해제.
- 잠금 해제 시 **상대 이동 궤적을 잠금 지점에 누적 → 애니 궤적 보존** (Motion Warping Skew 스타일).
- 일반 IK의 고무줄 pop 현상 해결.

### 4단계: 자세 해법
- 발끝 → 발목 역산. 계산 발목 높이 < 원본 애니 높이면 원본 덮어씀 (오르막 까치발).
- **골반 위치는 좌/우 중 더 높은 예상값 채택** → 오르막 다리 박힘 방지.
- **부작용 (내리막 발 스트레치)**: 내리막에선 더 낮은 골반 써야 자연스러움. 저자 권고: 방향별 분리.
- Two Bone IK 후처리: **피타고라스로 발끝 지면 정렬** (L² = A² + B², B = √(L²-A²)).

## SB2 환경 관련 확인 사항

- `PC_01_CtrlRig_FootClamp`: 단순 회전 클램프만. 위 4단계 대부분 미구현 추정.
- 애니 클립에 `contact_l/r` 커브 authoring 여부 확인 필요.
- 슬로프/계단 문제 진단 시 각 단계 존재 여부부터 점검.
